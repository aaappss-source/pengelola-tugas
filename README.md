# Pengelola Tugas

Buka aplikasi: https://aaappss-source.github.io/pengelola-tugas/

Aplikasi jadwal & checklist tugas (PWA). Tampilan di GitHub Pages, data disimpan di Google Spreadsheet
melalui Google Apps Script (`apps-script/Code.gs`, diterapkan sebagai aplikasi web: *Jalankan sebagai: Saya*, *Akses: Siapa saja*).

- `index.html` — aplikasi (satu file)
- `manifest.webmanifest`, `sw.js`, `icons/` — agar bisa dipasang seperti aplikasi
- `apps-script/Code.gs` — kode server (salinan)
